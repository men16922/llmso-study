# 04. 과제 제출 방법 및 규칙

## 과제 내용

스터디에서 학습한 내용을 간략히 정리하여 **공개된 링크에 글 작성 후 해당 링크를 공유**합니다.

### 작성 도구 (택일)

- 블로그
- GitHub
- 개인 홈페이지
- 개인 Youtube
- 페이스북 / 링크드인 **공개** 게시 글

### 정리 내용 예시 (하나 이상 선택)

1. 해당 주차 스터디에서 학습한 내용 요약 정리
2. 해당 주차에서 다룬 주제 기술 **1개를 별도 조사·학습**해서 정리
3. LLM 서빙 관련 **운영 경험** 중 기술 내용 위주로 정리
4. 최근 LLM 서빙 관련 **새로운 기술에 대한 분석** 정리

## ⚠️ 제명 규칙

> 작성 글 링크를 모두에게 공유해야 하며, **특별한 이유 없이 1회 미공유 시 멤버 제명**

## 제출 절차

1. **과제 제출표** 클릭 → 세부 페이지 진입
2. **자신의 이름** 클릭 → 작성한 URL 내용 추가
3. 세부 페이지에서 과제 스크린샷(이미지) 파일 업로드

### 주의 사항

- 해당 페이지는 **모든 멤버가 편집 권한**을 가짐 → 다른 멤버의 내용을 삭제/편집할 수 있음
- **자신의 이름을 정확히 확인 후** 업로드할 것
- (사고 발생 시 모임장이 페이지 편집 히스토리로 복원 가능)

> 과제 제출표는 노션에서 별도 작성 예정.

## (옵션) 멤버 기술 경험 발표

발표 희망 시 **모임장에게 슬랙 DM 문의**.

### 준비 가이드

- 설계 및 운영(자사/고객사)하고 있는 **LLM 서빙 관련 기술 위주**로 준비
- **회사 정보나 고객사 정보가 노출되지 않도록 제외** 필수
- 소재 예시:
  - 운영 중 발생한 트러블슈팅 사례와 대응 사례
  - 도입 검토 중인 아키텍처나 기술 분석 내용

### 혜택 / 조건

- 발표 시간: **10분 ~ 30분** (예약제)
- 멤버 경험 발표 시간은 **녹화하지 않음**
- 🎁 스터디 시간에 경험 발표 시 **모든 스터디 과제 면제**
