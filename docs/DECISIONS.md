# Decisions

되돌리기 어렵거나 나중에 "왜 이렇게 했지?"가 될 결정만 기록합니다.

## 2026-08-15 — `.sh`를 `.gitattributes`로 LF 고정

**맥락**: 이 저장소는 **Windows에서 체크아웃하고 WSL2에서 실행**합니다. `core.autocrlf`가 켜진 상태라 git에 LF로 저장된 `.sh`가 작업본에서 CRLF로 풀렸습니다.

**결정**: `.gitattributes`에 `*.sh text eol=lf` (+ `*.json text eol=lf`).

**근거**: 실패 방식이 **조용해서** 위험합니다. `source redeploy.sh`는 성공한 것처럼 종료하는데 bash가 `redeploy() {\r`를 파싱하지 못해 **함수가 정의되지 않습니다.** 그 결과 B1 스윕 루프가 전 구성을 "기동 실패"로 건너뛰고, 시나리오가 그 경우를 "KV cache 부족(= B3의 결과)"으로 안내하고 있어 **잘못된 결론에 이르기 딱 좋았습니다.** `sweep.sh`(C2)도 같은 상태였으므로 다음 편에서 똑같이 터졌을 것입니다.

**되돌리려면**: `.gitattributes`를 지우고 `git add --renormalize .`.

## 2026-08-15 — 2주차 과제 범위를 B1·B2로 축소

**맥락**: 08-09에 시나리오·도구를 완성했으나 6일간 측정이 진행되지 않았고, 마감(08-16 09:00)까지 하루가 남지 않았습니다. 원래 계획은 6.5~8시간·네 세션(B1·B2 / C1 / C2 / C3)이었습니다.

**결정**: **세션 1(B1·B2)만 수행**하고 C1·C2·C3는 다음 편으로 통째 이월. 시나리오 머리말의 잘라내기 순서(C3-4 → C1의 `bs` 축 → C2의 20ms)보다 한 단계 더 잘랐습니다.

**근거**: 시나리오가 스스로 남긴 안전판 — *"B1·B2만으로도 글 한 편이 선다"*. 실제로 배칭의 핵심 주장(슬롯이 천장을 정한다 / 비용은 TTFT로 청구된다 / goodput이 조용히 무너진다)은 전부 B1·B2만으로 증명됐습니다. C1의 `async def` 발견은 **측정 없이 코드 읽기만으로** 쓸 수 있어 "다음 편 예고"로 넣었습니다.

**대가**: 배칭 4종 종합표(없음/static/dynamic/continuous)를 못 채웠습니다. 글은 양 끝(없음·continuous)만 실측하고 가운데 둘을 다음 편으로 넘깁니다.

## 2026-08-09 — 게이트를 "문서 무결성"으로 정의

**맥락**: 하네스는 오프라인·결정론적 게이트를 요구하는데, 이 저장소에는 빌드도 테스트 파이프라인도 없습니다.

**결정**: `make check` = `scripts/check_docs.py`(링크·인덱스 스키마·파이썬 문법) + `labs/`의 기존 단위 테스트.

**근거**: 이 저장소에서 실제로 깨지는 것은 코드가 아니라 **문서 사이의 참조**입니다 — 파일을 옮기면 링크가, 인덱스를 재생성하면 스키마가 어긋납니다. `labs/`의 테스트는 localhost mock HTTP를 써서 GPU·네트워크 없이 1.4초에 끝나므로 게이트에 넣을 수 있었습니다.

**대안**: 마크다운 린터(markdownlint 등) 도입 — 외부 의존성이 늘고, 서식 취향을 강제할 뿐 참조 무결성은 검증하지 못해 기각.

**남은 구멍**: 게이트는 `meta.summary_method` 회귀(LLM 한국어 요약이 발췌로 되돌아감)를 잡지 못합니다. `docs/NEXT_PLAN.md` Priority 1 첫 항목.

## 2026-08-09 — `harness_root` 핀 고정

**맥락**: 이 머신에는 overnight-harness 사본이 `~/.claude`(등록된 1.2.0)와 `~/.codex`(1.2.0) 양쪽에 있고, `~/.claude` 캐시에는 등록되지 않은 1.3.x 잔재도 남아 있습니다.

**결정**: `.claude/harness-config.json`에 `~/.claude/.../1.2.0`을 명시 고정.

**근거**: Makefile의 자동 해석은 전체 경로를 `sort -V`하므로 `.claude` < `.codex` 정렬 때문에 **버전과 무관하게 Codex 사본**이 뽑혔습니다. 러너와 스킬이 서로 다른 설치에서 오는 상태를 막기 위함입니다.

**되돌리려면**: `harness_root` 줄을 지우면 자동 해석으로 돌아갑니다.
